# 手机抽屉与收藏反馈

本轮根据手机实测反馈调整交互，保留既有绿色主题、默认半展开列表和商户资料。当前只更新本地代码与56544预览，尚未再次部署生产站点。

## 已实现

- 店铺抽屉有三档：完全展开、半展开、完全隐藏。默认仍半展开。
- 向下拖可逐档收起，大幅拖动可直接到底；轻点拖动条在半展开/展开间切换。
- 顶部拖动条右侧增加44像素的收起按钮；展开状态底部“查看地图”、点击店铺定位也会完全收起。
- 完全隐藏后，标题、卡片、拖动条及阴影都移到屏幕外，隐藏内容不可聚焦或挡住地图。
- 地图底部保留“店铺列表 · 数量”和独立AI入口，点击列表按钮恢复半展开。搜索和切分类继续展开结果。
- 收藏和取消成功后显示约2秒的顶部提示；匿名用户须本地写入成功才改变爱心，已登录用户须远端成功才显示成功。
- 网络/权限失败显示保存失败；匿名浏览器存储被禁止或不足时说明无法保存，不假报成功。登录保存有10秒请求截止时间，同一店铺处理中不重复提交。
- 并行保存不同店铺时，在提交结果时读取最新收藏，避免覆盖另一家；离开页面或账号变化后不回写旧页面状态。
- 已登录用户远端保存成功但本地缓存被禁止时，仍可使用本次账号收藏状态。

```powershell
npm run i18n:check
npm run build

```

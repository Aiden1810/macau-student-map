## 发现并修复的问题

1. **旧账号的保存提示残留。** 切换账号或退出后旧提示仍显示；旧账号的异步刷新晚于退出失败时，也会重新显示旧提示。现在在身份/地点切换时清理提示，并用请求代次检查阻止旧结果回写。
2. **删除框默认焦点不正确。** React `autoFocus` 不足以保证原生 `showModal()` 后焦点仍在取消按钮，实际浏览器选中了确认删除。现在将取消按钮放在首位，已用真实浏览器验证默认回车取消。
3. **未知保存结果恢复后总分未刷新。** 刷新我的评价只恢复本人记录，外围列表和总分仍旧。现在增加独立 `onRefresh` 回调，重新读取后同步刷新外围数据；它与保存成功后的导航回调分开，避免刷新时误跳转。

修改文件：

- `components/reviews/ReviewForm.tsx`：上述三类修复。
- `app/[locale]/shop/[id]/page.tsx`、`components/MobileShopDetailModal.tsx`：接入手动恢复后的外围刷新。
- `tests/lib/reviews/form.test.tsx`：新增三个回归用例，并补充原生删除框初始焦点断言。

## 实际 Next.js 路由检查与限制

独立生产构建连接现有数据库时，实际检查结果：

- 未登录读取管理员评价：401 `UNAUTHORIZED`。
- 未登录读取本人评价：401 `UNAUTHORIZED`。
- 读取公开评价：503 `SCHEMA_UNAVAILABLE`，与新评价迁移尚未启用一致。
- 未登录的实际评价页面显示登录引导、携带站内返回路径，控制台无错误。

因此，不能将本报告解读为正式环境已经可用。仍需配套发布新应用和新迁移后，使用专用测试账号和测试地点核验真实邮箱登录、Supabase Auth、PostgREST 及线上完整写入流程；多连接高并发负载测试也不在本轮范围内。

本轮没有应用任何远端迁移，没有部署、发送登录邮件、写入真实评价或修改真实店铺资料，没有改动或输出 `.env.local`。测试完毕关闭本轮临时服务，原 56544 预览保留。

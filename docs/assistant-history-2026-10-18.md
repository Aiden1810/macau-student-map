# 城觅 AI：本地历史对话

## 本轮范围

在现有手机底部面板和桌面浮窗上增加历史记录，不改聊天识别接口、推荐规则或数据库。

- 标题栏历史图标打开列表；再次点击回到当前聊天。
- 第一条问题自动作为标题，旁边显示最近活动时间；未发送内容显示“草稿”。
- 新建、继续和删除对话；每段草稿与最近6条用户问题分别保存。
- 刷新、离开首页后重新打开助手，恢复最近一段已保存对话。
- 切换、新建、删除当前对话时取消请求，并用请求序号隔离过期结果。
- 已中断的回答恢复为提示文字，不恢复永久加载；尚未完成的门店或起点确认需重新发送问题。

## 保存方式与边界

数据使用浏览器 `localStorage`，键为 `chengmi-assistant-history-v1`，带版本号并由 Zod 校验。

- 最多20段，每段最近80条消息，草稿1200字符，总存储上限600,000字符。
- 空白新对话不入历史；只有草稿的记录在删空草稿后移除。
- 空间不足时尝试移除最旧的非当前记录；当前记录无法保存时显示提示，保留本次内存聊天。
- 无法读取、记录损坏或版本不支持时显示提示，不覆盖原始损坏数据。
- 保存已确认公开门店的身份信息，供追问识别分店；价格和标签不作为可继续使用的缓存事实。
- 路线保存为带原查询时间的文字摘要，包含当时真实返回的时间、距离和公交线路。恢复后不展示旧导航按钮，不自动重查路线。
- 不持久化精确出发地坐标；历史正文仍可能包含用户自己输入的地点名称或文字信息。
- 恢复的回答显示“历史回答”。继续提问重新读取门店资料，需要查询路线时重新确认起点。
- 只属于当前浏览器和网站地址，不与登录账号绑定；不同设备、浏览器或端口不共享。清除网站数据会移除记录。
- 当前不做多标签页合并；同时编辑时以后一次保存为准。

## 本地运行与验证

```powershell
npm test
npm run lint
npx tsc --noEmit --incremental false
npm run i18n:check
npm run build
npm run start -- --port 56544
```

启动前确认56544是否已有本项目预览；已有服务时关闭该服务后再启动，避免端口冲突。访问 `http://localhost:56544/zh-CN`，打开“AI助手”。

手动步骤：发送问题 → 留下草稿 → 新建另一段 → 打开历史选择前一段 → 刷新并重新打开 → 继续追问。另检查回答中途切换、删除当前记录、删空未发送草稿。截图和本轮实际结果记录在 `design-qa.md` 的历史对话小节。

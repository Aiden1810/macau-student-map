# 外卖店铺资料整理提示词

复制下面的内容给负责搜集资料的 AI，把最后的店名和线索替换成真实信息。每家店分别整理，结果交回后用于管理员录入；目前尚未提供两个店铺的名称，因此没有新增店铺记录。

```text
请帮我整理以下外卖餐饮店铺的资料，用于学生生活服务网站的管理员录入。网站消费参考统一使用人民币（CNY）。请以可核实的事实为先，不要为了填满表格编造信息。

资料规则：
1. 优先使用我提供的外卖菜单、订单、商家主页、照片和截图；需要补充时查询商家官方信息、外卖平台或地图中的同一分店。关键结论注明来源链接或截图名称及查询日期。无法联网时明确说明，只整理我提供的资料。
2. 先核对店名、具体分店、地址、所在城市，避免混合同名店。地点类型为“饭店”；餐饮具体类型从现有选项选择：中餐、葡国菜、茶餐厅、火锅、西餐、日料、韩餐、烧烤、小食、快餐、东南亚菜、咖啡、奶茶、水果茶、面包、甜品、蛋糕、汉堡、炸鸡。选最主要的 1–3 个；无法判断写“待确认”。
3. 人均消费是“一人正常吃一餐的餐品费用”，使用人民币元。列出可核实的普通单人餐/套餐价格、范围、建议录入的一个代表值及计算理由。配送费、打包费单列；区分日常价格与首单、满减、会员、临时优惠。不能把起送价、多人套餐总价当成人均。资料不足时建议值写 null，不写 0；0 在网站表示免费。
4. 来源是澳门元等其他币种时，保留原币价格；只有能提供汇率来源及日期时才另列人民币估算并注明“约”。无法核实汇率时人民币值写 null，不能把原币数字直接当人民币。
5. 外卖信息注明平台、店铺链接、可核实的配送范围、费用及起送条件。“可外卖”标签需要证据；不能因为商家在珠海或地图上有店，就声称能送到澳门、学校或我的具体地址。
6. 补充搜索关键词最多 8 个，每个不超过 40 字，优先店名别称、招牌菜、餐品类型等可核实内容。不要把“最好吃”“全城第一”等主观评价当事实。补充标签只推荐证据支持的已有标签，例如可外卖、学生优惠、深夜营业、聚餐。
7. 给出可核实的招牌餐品、营业时间及营业状态。平台“休息中/暂不接单”不等于永久停业；缺失或冲突写“待确认”，列出冲突。
8. 地址尽量精确到分店；坐标只有来源和坐标系明确时才提供，并注明 GCJ-02/WGS84 等。否则留空，后续由管理员从地图选择，禁止猜坐标。
9. 只整理我提供或允许使用的图片；其他图片只给来源链接并标明使用权限待确认，不声称网络图片可以随意使用。

每家店分别按下列格式输出：
一、可录入资料：中文名、英文名（无则留空）、具体分店、城市/区域、详细地址、地点类型、餐饮具体类型、人均消费参考（人民币单个值或 null）、补充标签、补充搜索关键词、营业状态、可用图片。
二、外卖说明：平台与链接、配送范围及条件、配送费/打包费、营业时间；未知项标注待确认。
三、价格依据：普通单人餐价格、是否优惠价、建议人均值的计算过程。
四、证据清单：字段—来源链接/截图—对应证据—查询日期。
五、待确认事项：尤其是同名分店、价格、配送到目标地址、营业状态、地图位置。最后写一句“资料是否足够录入；哪些内容需要管理员确认后才能发布”。

待整理店铺：
1. 店名：【填写第一家店名及分店】
2. 店名：【填写第二家店名及分店】
所在城市/目标配送地址：【填写；不知道可留空】
我提供的菜单、截图、订单或链接：【粘贴或附上】
```
